# Joearasin Tap

## How do I install these formulae?

`brew install joearasin/tap/<formula>`

Or `brew tap joearasin/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "joearasin/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
